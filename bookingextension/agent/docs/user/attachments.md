# Attaching files

Some requests work better — or only work — when you attach a file. The Booking Assistant can use an **image** as a booking option's header image, and a **PDF** either to generate quiz questions or to read. This page explains when and how to attach files, and what the assistant does with them.

## When you'd attach a file

There are two main reasons to attach something:

- **An image** — to set the header image of a booking option.
- **A PDF** — to generate quiz questions from it, or to have the assistant read it.

If a request needs a file and you haven't attached one, the assistant tells you it expects a file. You won't be left guessing — it asks for what it needs.

## Attaching an image for a header image

A booking option can have a header image — the picture shown at the top. To set one, attach the image when you make your request, and say what you want done with it:

- "Add this image as the header for the **Beginner Yoga** option." *(attach the image)*
- "Set this picture as the header image of the option we just created." *(attach the image)*
- "Update the **Pottery Workshop** header image to this one." *(attach the image)*

The assistant treats the attached image as the header for the option you named. As with any change, it shows you a preview and waits for your confirmation before saving — see [confirmations and safety](confirmations-and-safety.md). If it's not clear which option you mean, it asks you to pick (see [choosing the right item](choosing-the-right-item.md)).

## Attaching a PDF to generate quiz questions

The assistant can turn a PDF into quiz questions. Attach the PDF and ask:

- "Generate quiz questions from this PDF." *(attach the PDF)*
- "Create quiz questions based on this document and add them to the Photography quiz." *(attach the PDF)*
- "Make a set of questions from this file for the Module 3 quiz." *(attach the PDF)*

The assistant reads the PDF and prepares the questions. Because adding questions is a change, it previews what it's about to do and waits for your OK before anything is saved. You can review the proposed questions and confirm, say no, or ask it to adjust.

If you ask to generate quiz questions but don't attach a file, the assistant tells you it needs the PDF.

## Attaching a PDF for the assistant to read

You can also attach a PDF simply so the assistant can read it and work with its contents — for example to answer a question about it or to use it as the basis for something you're building. Attach the PDF and tell it what you want:

- "Read this PDF and summarise the key points." *(attach the PDF)*
- "Use this document to help me set up the course." *(attach the PDF)*

## It tells you when it expects a file

You don't have to remember the rules. If your request implies a file — like asking for a header image or quiz questions from a document — and nothing is attached, the assistant prompts you:

> **You:** Add a header image to the Beginner Yoga option.
>
> **Assistant:** Sure — please attach the image you'd like to use as the header, and I'll set it on *Beginner Yoga*.

Attach the file and the assistant carries on. The same applies to PDFs for quiz questions: it asks for the document if you haven't provided one.

## Tips

- **Attach the file with the same message** where you describe what to do with it, when you can — it keeps things clear.
- **Use an image for header images** and a **PDF for reading or quiz questions** — those are the file uses the assistant supports.
- **Name the target** (which option, which quiz) so the assistant applies the file to the right place. If it's unclear, it'll ask.
- **You still confirm.** Setting a header image or adding generated questions are changes, so you'll see a preview and confirm before anything is saved.

For the basics of starting a conversation, see [getting started](getting-started.md); for how previews and confirmations work, see [confirmations and safety](confirmations-and-safety.md).
