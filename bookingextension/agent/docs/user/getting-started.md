# Getting started with the Booking Assistant

The Booking Assistant is an AI helper built into Moodle. You tell it what you want in plain words, and it helps you create and edit booking options, set up courses, find people, answer questions, and diagnose problems — all using your own Moodle permissions.

This page shows you how to open it, what the chat looks like, and the first things to try.

## Opening the assistant

There are two ways to start a conversation.

- **From anywhere — the wand icon.** Look for the small magic-wand icon in the top navigation bar. Click it and a chat panel opens. This works on most pages, so you can ask for help wherever you are.
- **From a Booking activity.** When you are inside a Booking activity, you can open the assistant there too. It will already know which Booking activity you are looking at, so you don't have to name it.

Wherever you open it, the assistant works in the context you are in. If you opened it inside a course or a Booking activity, it assumes you mean that course or activity unless you tell it otherwise. See [choosing the right item](choosing-the-right-item.md) for how to point it somewhere else.

## The chat box

The assistant is a simple chat. There is a message box at the bottom where you type your request, and the conversation appears above it. You write a message, the assistant replies, and you keep going from there.

You don't need any special syntax or commands. Write the way you would explain a task to a colleague. Full sentences, short phrases, follow-up questions — all of it works.

## Sending your first request

Type what you want and send it. For example:

- "Show me the booking options in this activity."
- "Create a booking option called Beginner Yoga on Mondays at 6pm."
- "Who is enrolled in this course?"
- "Why can't this student book the Tuesday class?"

The assistant reads your message, works out what you mean, and replies. If your request would **change** something, it first shows you a preview and waits for your confirmation before doing anything. If your request is just a **question**, it answers right away. See [how it works](how-it-works.md) and [confirmations and safety](confirmations-and-safety.md) for the full picture.

## What a typical exchange looks like

Here is a normal back-and-forth:

> **You:** Create a booking option called Pottery Workshop on 5 March from 10am to 1pm, place is Studio B, price 25.
>
> **Assistant:** Here's what I'll create: *Pottery Workshop*, 5 March 10:00–13:00, place Studio B, price 25.00. Shall I go ahead?
>
> **You:** Yes.
>
> **Assistant:** Done — I've created Pottery Workshop in this activity.

Notice the pattern: you describe it, the assistant shows you a preview, you say yes, and only then does it make the change. You can always say "no", or just rephrase your request, and nothing is saved.

## The first things to try

If you're new, these are good warm-up requests:

- **Look around:** "List the booking options here" or "Show me the details of the Friday session."
- **Make something:** "Create a booking option named Intro Session next Monday at 9am."
- **Find someone:** "Find the user Maria Sanchez" or "Show me who is enrolled in this course."
- **Ask a how-to question:** "How do I add a header image to a booking option?" The assistant can answer from its own help documentation.
- **Diagnose a problem:** "Why can't Tom see this activity?" or "Why didn't this student get the confirmation email?"

## Writing in your own language

You can write in any language, and the assistant replies in the same one. Switch languages between messages whenever you like — it follows your lead. See [languages](languages.md).

## A few things to know

- The assistant always acts with **your** Moodle permissions. It can only do and show what your account is allowed to. If you're not allowed to do something, it won't.
- It **never does more than you asked**. It won't make extra changes or tidy things up on its own.
- It can attach meaning to files you upload — for example an image for a header, or a PDF to read or to turn into quiz questions. It will tell you when it expects a file. See [attachments](attachments.md).
- Your earlier messages stay in the conversation, so you can refer back ("change the one we just made") and it remembers. Personal data in the saved conversation is masked for privacy — see [privacy](privacy.md).

When you're ready, just open the chat and type your first request.
