# FAQ

## Does it change things without asking?

No. Before any change — creating or editing an option, booking a person, adding an activity,
enrolling someone — the assistant shows you a preview and waits for your confirmation. Only
read-only questions are answered immediately. See [Confirmations and safety](confirmations-and-safety.md).

## What is it allowed to do?

Exactly what **you** are allowed to do. It acts with your permissions in the current course or
activity — it cannot do anything you could not do yourself in Moodle. Some actions (enrolment,
groups, calendar, messages, reports) need manager-level rights; if you don't have them, the
assistant tells you.

## In which language does it answer?

In the language you write in. Ask in German and you get German; ask in English and you get
English. You can switch languages between messages. See [Languages](languages.md).

## Can it see other people's personal data?

Only what you are already entitled to see, and personal data is masked in the saved
conversation. It will not expose the contact details of users you have no relationship with.
See [Privacy](privacy.md).

## It picked the wrong option / course / person. What now?

Name the item more specifically (its exact title, the person's full name). If several match,
the assistant asks you to choose rather than guessing. You can also cancel at the confirmation
step and rephrase. See [Choosing the right item](choosing-the-right-item.md).

## Can it delete an option or cancel someone's booking?

No. It can **create** and **edit** options and **book** people, but it has no action to delete
a booking option or to cancel a booking on someone's behalf. It can, however, *diagnose* why a
person can't cancel.

## Can I do several things in one request?

Yes. For a multi-part request it works through the steps in order and confirms each change as
it goes. See [Multi-step requests and limits](multi-step-and-limits.md).

## Can it remember my preferences?

Yes — ask it to remember something ("always default to 20 places") and to forget it later.
These notes are kept for your account only. See [Remembering and history](remembering-and-history.md).

## How do I attach a file?

When a task needs a file — an image for an option's header, a PDF to generate questions — the
assistant prompts you, and you attach it in the chat. See [Attachments](attachments.md).

## Something went wrong / it couldn't do it

It tells you what went wrong in plain language. Common reasons: you lack the permission, a
required detail was missing or ambiguous, or a file was expected. Adjust your request and try
again — see [Troubleshooting](troubleshooting.md).

## Can I ask it how a feature works?

Yes. Ask "how does X work?" and it searches this help and gives a short answer with the
relevant passage; ask it to read more for the full detail. See [Getting help](getting-help.md).
