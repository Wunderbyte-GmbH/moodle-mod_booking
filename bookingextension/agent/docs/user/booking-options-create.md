# Creating a booking option

A booking option is a single bookable thing inside a Booking activity — a course session, an
event, a workshop, an appointment. You can create one just by describing it to the assistant in
plain words. You don't need a form, and you don't need to fill in everything: give as much or as
little detail as you like, and the assistant asks you for anything that's required but missing.

Before it creates anything, the assistant shows you a preview of the new option and waits for
your confirmation. Nothing is saved until you say yes. See
[confirmations](confirmations-and-safety.md).

## Just say what you want

You can describe the whole thing in one sentence, or build it up over a few messages. Some
examples of what you might type:

- "Create a booking option called *Intro to First Aid* on 5 March at 14:00, 12 places."
- "Add a new session *Excel for Beginners*, 10 April 09:00–12:00, room B2, 20 places, 25 €."
- "New option: *Yoga at lunchtime*, every detail is in the description below…"
- "Make a booking for the guided museum tour on 18 May, 2 pm, max 30 people."
- "Create *Team Photography Walk*, Saturday morning, meeting point at the main entrance."

If you leave something out, that's fine. The assistant fills in sensible defaults where it can
and asks you about anything it genuinely needs.

## What you can include

You can mention any of these in your request, in any order and any wording:

- **Name / title** — what the option is called, e.g. *Intro to First Aid*. This is the one thing
  the assistant will always make sure it has, because it's how the option is found and shown.
- **Date and time** — "5 March at 14:00", "10 April 09:00–12:00", "next Monday morning". You can
  give a start time only, or a start and end.
- **Number of places** — how many people can book, e.g. "12 places", "max 30 people". Leave it
  out if the option is unlimited.
- **Location** — a room or place, e.g. "room B2", "meeting point at the main entrance".
- **Description** — any free text explaining the option. You can dictate it inline or paste it
  in.
- **Price** — e.g. "25 €", "free". You can also set different prices for different groups of
  people (for example a student price) — see
  [prices and bulk changes](booking-options-prices-and-bulk.md).

## Minimal versus detailed requests

**Minimal** — you give almost nothing and let the assistant ask:

- "Create a new booking option." → the assistant asks you for a title, and anything else it
  needs.

**Detailed** — you put everything in one go:

- "Create *First Aid Refresher* on 12 March 13:00–16:00 in room A1, 15 places, price 40 €, and
  a description saying participants should bring their certificate from the previous course."

Both work. A detailed request just means fewer follow-up questions.

## If something required is missing

When a required detail is missing, the assistant asks you a short, specific question — for
example "What should the option be called?" or "How many places should it have?" Answer in one
line and it carries on. You can also add or correct details after seeing the preview.

## Which activity it goes into

A booking option always lives inside a Booking activity. If you start from inside a Booking
activity, the assistant creates the option there. If it's not clear where the option should go,
the assistant asks you to confirm the right activity before creating anything. See
[choosing the right item](choosing-the-right-item.md).

## Before it saves: the preview

Once it has what it needs, the assistant shows you a preview of the option — its title, date and
time, places, location, price and description as it understood them. Check it over. If something
is wrong, tell the assistant what to change ("make it 14 places", "the room is B3") and it
updates the preview. When it looks right, confirm, and the option is created.

## Other kinds of option

The steps above create a **standard** booking option. The assistant can also create self-paced
("self-learning") options and slot/appointment options — see
[the kinds of option you can create](booking-options-types.md).
